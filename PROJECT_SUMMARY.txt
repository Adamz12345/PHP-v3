QUICK START
================================================================================

STEP 1: Choose Your Platform
  └─ Next.js? Go to NEXTJS_SETUP.md
  └─ PHP? Go to PHP_COMPLETE_SETUP.md
  └─ Not sure? Go to QUICK_START.md

STEP 2: Get API Keys
  1. Visit https://dashboard.flutterwave.com
  2. Create account or log in
  3. Go to Settings → API Keys
  4. Copy Public Key and Secret Key

STEP 3: Set Up Environment
  • Copy .env.example to .env.local (Next.js) or .env (PHP)
  • Add your Flutterwave keys

STEP 4: Install & Run
  Next.js:
    npm install
    npm run dev
  
  PHP:
    composer install
    php -S localhost:8000

STEP 5: Test
